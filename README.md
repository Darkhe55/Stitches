# 缝线 Stitches

一个基于 Web 的缝线（Stitches）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5202/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 每对相邻区块之间恰好缝 **K** 条线（经典 **1÷** 时 K=1；**3÷** 变体 K=3，K 由题面决定，缺省 1）
- 只能缝在不同区块的相邻格之间，不能斜缝
- 每格最多一个针孔
- 盘外数字表示该行或该列上的针孔总数

## 操作

| 操作 | 说明 |
|------|------|
| 左键点相邻格之间的边 | 缝线 / 取消 |
| 右键点边 | 清除缝线 |
| 按住拖动 | 连续缝线 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **变体**：规则 / 校验 / 求解 / 渲染 / 导入均按「每对相邻区块 K 条线」工作，支持 1÷、3÷ 等（K=1..9）
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由；回放中按钮变为停止，按 `P` 暂停/继续
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

## 图片识图导入

```bash
# 预览：识别区域 + 行列数字 + 变体 K，不写入题库
npm run import-image -- 题图.png

# 识别并追加到题库（自动识别 1÷ / 3÷ 等变体并写入 k 字段）
npm run import-image -- 题图.png --append --name "识图 · 15×15" --verify
```

| 参数 | 说明 |
|------|------|
| `--name 名称` / `--id ID` / `--series 系列` | 题库条目信息 |
| `--append` | 写入 `src/game/puzzles-data.ts`（含 `k` 字段） |
| `--verify` | 额外校验唯一解（超时只警告） |
| `--k N` | 变体 K 人工指定（1..9）；OCR 数字有误导致变体推算失败时使用 |
| `--map 簇号=数字` | 数字 OCR 识别簇人工修正，如 `--map 3=1` |
| `--budget N` | 求解节点上限 |
| `--dry` | 只识别并打印区域/数字/变体，不求解、不写入 |

- 识别原理：深色像素投影找网格线 → 逐条格线测线宽并用 k-means 分成「细网格 / 粗区域边界」→ 洪泛出区域 → 上方/左侧数字连通域切字、与内置粗体数字模板 IoU 匹配。
- 变体判定：脚本由「行/列数字和 ÷ 2 ÷ 相邻区域对数」推算每对区域需要的缝线数 K，要求是 1..9 的整数（否则多为 OCR 错误，可用 `--map` 修正数字或用 `--k` 指定）。K=1 为经典 1÷，K=3 为 3÷。
- `month3线.png` 是 **3÷** 题图：15×15、8 个区块、11 对相邻区块、行列数字和均为 66 → 33 条缝线 → 每对 3 条。可正常导入并求解（唯一解）。
- 变体支持范围：规则传播、唯一性校验、回溯求解、逻辑回放、SVG 渲染（含 `K÷` 徽标与两位数盘外数字）、导入器均按 K 工作；旧 1÷ 题库（无 `k` 字段）继续按 K=1 解析，完全兼容。
- `npm run gen` 会覆盖 `puzzles-data.ts` 中的导入内容。

### 题库数据格式

`board` = `区域串|行数字|列数字`（可选第 4 段 K）：

- 区域串：每格一个 base36 字符（区域号 0..9a..z）；
- 行/列数字：默认每数字一位 `0..9`；存在两位数（如 10）时自动改用逗号分隔整数，如 `3,9,7,10,...`；
- `k` 字段（可选）：每对相邻区域需要的缝线数，缺省 1。

## 题板尺寸与形状支持

- **题面模型**：区域矩阵 + 盘外行/列针孔数 + 变体 K，`width × height` 独立；
  渲染、命中、校验、唯一性求解、逻辑回放都按宽高分别计算。
- **内置题库**：7×7 正方形（K=1 与 3÷ 变体）。
- **自定义题板**：**暂不支持**（`mode: 'none'`）。原因：需要「区域层 + 盘外数字层 + K」三层录入，
  现有通用编辑器没有「盘外数字」模式；只做区域层会生成没有行列数字的残题。
- **识图导入**：支持非正方形大盘：`month3线.png` 为 15×15、8 区块、K=3，导入后可求解且唯一解。
- **异形棋盘**：不支持（区域覆盖全部格子，盘外数字按整行整列统计）。
- **验证**：`npm run build`、`npm run check` 通过；15×15 3÷ 与 7×7 1÷ 题库均通过唯一解校验；
  宽高参数在渲染/求解/导入链路中均为独立变量。
- **限制**：没有自定义题板；大棋盘（≥15×15）的唯一性/求解会超时（有预算上限）。
