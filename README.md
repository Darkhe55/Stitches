# 缝线 Stitches

一个基于 Web 的缝线（Stitches）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5202/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 每对相邻区块之间恰好缝一条线
- 只能缝在不同区块的相邻格之间，不能斜缝
- 每格最多一个针孔
- 盘外数字表示该行或该列上的针孔总数

## 操作

| 操作 | 说明 |
|------|------|
| 左键点相邻格之间的边 | 缝线 / 取消 |
| 右键点边 | 清除缝线 |
| 按住拖动 | 连续缝线 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由；回放中按钮变为停止，按 `P` 暂停/继续
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

## 项目结构

```
src/
  main.ts
  core/
    app.ts / ui.ts / view.ts      界面、交互、缩放、回放控制
    store.ts / library.ts         题库、进度、上次题目存储
    audio.ts / fx.ts              音效与落子特效
  game/
    adapter.ts                    游戏规则接入
    rules.ts                      推理规则
    logic.ts                      逻辑解题回放
    render.ts / state.ts          SVG 渲染与盘面状态
    validate.ts / solver.ts       实时校验与回溯求解
    puzzles.ts / puzzles-data.ts  题库加载与静态题库
```

## 命令

```bash
npm run dev       # 开发服务
npm start         # 开发服务 + 自动打开浏览器
npm run build     # tsc --noEmit + vite build
npm run gen       # 重新生成题库
npm run check     # 审计题库
npm run verify    # 参考解、逻辑回放与交互验证
npm run audit     # 逐题审计逻辑解题
```

## 图片识图导入

```bash
# 预览：识别区域 + 行列数字，不写入题库
npm run import-image -- 题图.png

# 识别并追加到题库（1÷ 变体题图）
npm run import-image -- 题图.png --append --name "识图 · 15×15" --verify
```

| 参数 | 说明 |
|------|------|
| `--name 名称` / `--id ID` / `--series 系列` | 题库条目信息 |
| `--append` | 写入 `src/game/puzzles-data.ts` |
| `--verify` | 额外校验唯一解（超时只警告） |
| `--map 簇号=数字` | 数字 OCR 识别簇人工修正，如 `--map 3=1` |
| `--budget N` | 求解节点上限 |
| `--dry` | 只识别并打印区域/数字，不求解、不写入 |

- 识别原理：深色像素投影找网格线 → 逐条格线测线宽并用 k-means 分成「细网格 / 粗区域边界」→ 洪泛出区域 → 上方/左侧数字连通域切字、与内置粗体数字模板 IoU 匹配。
- 变体判定：脚本会由「行/列数字和 ÷ 2 ÷ 相邻区域对数」推算每对区域需要的缝线数。当前游戏规则/求解器只实现 **1÷**（每对相邻区域恰好 1 条线）；遇到 3÷ 等变体会明确报错，不会导入成不可解题目。
- `month3线.png` 正是 **3÷** 变体题图（相邻区域对 11、数字和 66 → 每对 3 条线），因此不会导入；请用 1÷ 题图测试。
- `npm run gen` 会覆盖 `puzzles-data.ts` 中的导入内容。
